Contributing

Five ways to help

No contribution is too small — early projects thrive on many small hands.

Report issues

Found a bug or a sharp edge? File a GitHub issue — a clear repro is the best first contribution.

Submit pull requests

The compiler is young — lexer, parser, codegen, tests: plenty of surface to learn on and improve.

Write documentation

This reference lives next to the code. Clarify a section, fix a typo, or add an example that clicked for you.

Test early

Try the language as it evolves, break it on purpose, and report what surprised you. Honest feedback shapes syntax.

Spread the word

Star the repo, share the project, and invite curious friends into the Discord. Communities grow one person at a time.

Propose design ideas

Have an opinion on syntax or semantics? Open a discussion on GitHub — the design is still being written.

Show & tell. Built something in Tinoc — a snippet, a demo, a wild idea? Drop it in the Discord's show-and-tell channel. The compiler is young, so every working example is a small milestone for the whole community.
Get involved

Say hello.

Introduce yourself on Discord, open your first issue, or just star the repo. The door is open.
