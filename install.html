Install

Get Tinoc

v0.1.0 is released. Install the latest release binary into ~/.tinoc — no root needed — and start transpiling to C11.

v0.1.0 · August 5, 2026. The first public release ships prebuilt binaries for macOS, Linux, and Windows (amd64 + arm64). Installers verify downloads against the release SHA256SUMS manifest, track versions, and ask before upgrading.
Quick install

One command, any platform

The installers are companions to build.sh / build.ps1 — they fetch the latest release from GitHub, verify it, and extract it into ~/.tinoc/ (or $TINOC_HOME).

macOS & Linux

terminal
curl -fsSL https://raw.githubusercontent.com/tinoc-lang/tinoc/main/install.sh | bash

Detects your OS/architecture and installs the matching binary. Offers to add ~/.tinoc/bin to your PATH.

Windows (PowerShell)

terminal
irm https://raw.githubusercontent.com/tinoc-lang/tinoc/main/install.ps1 | iex

install.ps1 is fully cross-platform: it detects the OS/architecture just like install.sh, so it works on macOS/Linux with PowerShell 7+ as well as Windows.

What you get

Verified, versioned, updatable

The installers are built for careful systems programmers.

Verified downloads

Every release ships a SHA256SUMS manifest. The installer fetches it from GitHub and verifies the binary before extracting.

Version tracking

A VERSION file sits next to the install. Re-running the installer checks for updates and asks before upgrading.

No root needed

Everything installs into ~/.tinoc (or $TINOC_HOME). The installer offers to add ~/.tinoc/bin to your PATH.

Build from source

--local builds from source with ./build.sh build (or ./build.ps1 build) and installs the local binary instead of downloading.

Flags

Installer options

Run install.sh --help for the full list.

FlagWhat it does
--checkCompare the installed version against the latest release without installing.
--uninstallRemove Tinoc from ~/.tinoc.
--version 0.1.0Install a specific release instead of the latest.
--force / --yesSkip prompts and reinstall over an identical installed version.
--dir <path>Override the install directory.
--localBuild from source and install the local binary.
--verbosePrint the download/fetch commands the installer runs.
Requirements

What your system will need

Only the tools C developers already use.

A C11 compiler

GCC, Clang, or MSVC. Tinoc emits standards-compliant C11, so the C compiler is the only system dependency at build time.

The tinoc CLI

A single binary with build, run, and check subcommands, plus tinoc version / tinoc help.

tinoc.h

One small C11 runtime header embedded in the compiler. It defines str, slices, optionals, and saturating arithmetic via _Generic.

Quick start

Write, compile, run.

A hello world is three commands: write, build, run. The emitted C11 is yours to inspect, audit, and commit — tinoc run leaves no binaries behind.

terminal
$ tinoc run main.tnc
Hi, Tinoc!

$ tinoc build main.tnc
  ✓ emitted main.c
